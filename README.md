# 🚀 My Personal Portfolio

¡Bienvenido/a a mi portfolio personal! Este proyecto es mi carta de presentación al mundo del desarrollo web moderno. Aca centralizo mi trayectoria profesional, mis proyectos actuales y las tecnologías que domino.

El sitio está diseñado con un enfoque **Mobile-First**, asegurando una experiencia fluida tanto en escritorio como en dispositivos móviles.

---

## 🛠️ Tecnologías Utilizadas

Este proyecto fue construido utilizando el ecosistema de **React** y herramientas modernas para garantizar un código limpio y tipado:

* **Frontend:** [React.js](https://reactjs.org/) & [TypeScript](https://www.typescriptlang.org/) (para robustez y escalabilidad).
* **Estilos:** [CSS3](https://developer.mozilla.org/en-US/docs/Web/CSS) con metodologías modernas de diseño responsivo.
* **Gestión de Contacto:** [EmailJS](https://www.emailjs.com/) (integración de API para envío de correos sin backend propio).
* **Despliegue:** [GitHub Pages](https://pages.github.com/).

---

## ✨ Características Principales

* **Tipado Estricto:** Uso de interfaces y tipos de TypeScript para reducir errores en tiempo de ejecución.
* **Formulario de Contacto Funcional:** Integración directa con servicio de mensajería externa.
* **Diseño Responsivo:** Adaptabilidad total a diferentes resoluciones de pantalla.
* **Sección de Proyectos Dinámica:** Array de objetos estructurado para facilitar la actualización de contenido.

## 🚀 Cómo Levantar el Proyecto Localmente

Si querés explorar el código o correrlo en tu máquina, seguí estos pasos:

1.  **Clonar el repositorio:**
    ```bash
    git clone [https://github.com/Selee-Posadas/portfolioSp.git](https://github.com/Selee-Posadas/portfolioSp.git)
    ```

2.  **Configurar variables de entorno:**
    Crea un archivo `.env` en la raíz del proyecto basándote en el archivo `.env.template` y completa tus credenciales de EmailJS:
    ```env
    VITE_EMAILJS_SERVICE_ID=tu_service_id
    VITE_EMAILJS_TEMPLATE_ID=tu_template_id
    VITE_EMAILJS_PUBLIC_KEY=tu_public_key
    ```

3.  **Instalar dependencias:**
    ```bash
    npm install
    ```

4.  **Ejecutar en modo desarrollo:**
    ```bash
    npm run dev
    ```
